FPL AI Manager

AI-Powered Fantasy Premier League Team Optimization

About This Project

FPL AI Manager is an AI-powered assistant that helps Fantasy Premier League players make data-driven decisions. Using machine learning models trained on historical data, it provides:

  • Optimized team suggestions based on expected points
  • Smart transfer recommendations
  • Captain and vice-captain picks
  • Gameweek strategy optimization
  • Chip timing suggestions (Wildcard, Triple Captain, etc.)

Technology Stack

Python scikit-learn XGBoost Pandas FastAPI GitHub Actions
Features

What It Does

Points Prediction

ML models predict expected points for each player based on form, fixtures, and historical performance.

Transfer Optimization

Identifies highest-value transfers considering budget, team balance, and upcoming fixtures.

Team Selection

Optimal starting XI and bench order for each gameweek based on predicted points.
