OpenFPL Scout AI

Advanced machine learning-powered tool for Fantasy Premier League player performance prediction and team optimization.

Advanced FPL Optimization Tool

OpenFPL Scout AI leverages machine learning models (XGBoost, CatBoost) trained on historical player data to predict performance and provide data-driven insights for Fantasy Premier League team selection and optimization.

Project Highlights

ML-Powered Predictions

Advanced machine learning models (XGBoost, CatBoost) trained on historical player performance data to predict future FPL points.

Real-time Insights

Live player performance metrics, injury reports, and price trends to make informed FPL decisions every gameweek.

Optimization Engine

Intelligent squad and formation optimization suggestions based on budget constraints and predicted player performance.

Open Source

Fully open-source project available on GitHub. Contributions welcome from the FPL and ML community.

Tech Stack

Python • XGBoost • CatBoost • Pandas • FastAPI • Docker • Cloud Run
